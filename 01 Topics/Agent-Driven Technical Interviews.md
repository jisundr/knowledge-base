# Agent-Driven Technical Interviews

Replace algorithmic (DSA / LeetCode-style) coding interviews with exercises that test how a candidate works with agents: judging an agent-written design, debugging an agent-generated PR, and directing agents through a larger project.

Anthropic phased out coding interviews across its product and platform teams. Their reasoning: candidates who failed the hand-coding round often did very well in system design, trade-off analysis, and execution, and engineers no longer write most code by hand, so whiteboard algorithms predicted little about the job.

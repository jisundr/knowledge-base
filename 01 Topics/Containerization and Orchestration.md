# Containerization and Orchestration

Packaging agents, dependencies, and local model microservices into standardized containers (Docker, Kubernetes) ensures reliable execution across hybrid cloud infrastructure.

Part of Tier 3 (deployment and operations), alongside observability (tracing model calls, database queries, tool interactions) and monitoring/security (app health, safeguards, token costs).

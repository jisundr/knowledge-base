# AI Engineer Skill Stack

An **AI engineer** wires existing frontier or open-source models into working systems (data sources, tools, memory loops, guardrails, APIs). An **ML researcher** trains foundational models and develops new architectures.

> Analogy: ML researchers build the engine; AI engineers build the car.

## Tier 1: Foundation

- **Python**: fluent enough to read code, understand what an agent generates, and use ML libraries (PyTorch, TensorFlow).
- **Linux, CLIs, Git**
- **APIs**: calling models, handling responses, managing rate limits.

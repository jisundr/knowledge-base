# Ubiquitous Language

A shared, precise project vocabulary used by everyone (and every agent) working on a system; a core idea of Eric Evans' *Domain-Driven Design*.

For agents, keep it in a project `GLOSSARY.md`. A coined term replaces a multi-sentence explanation (e.g., "materialization cascade" for "making a lesson real in the file system"), which saves [[Smart Zone and Dumb Zone|smart-zone]] tokens in every later session and makes the codebase easier for the agent to navigate.

Usually emerges from a [[Grilling Session]].

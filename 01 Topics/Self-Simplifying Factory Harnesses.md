# Self-Simplifying Factory Harnesses

Traditional systems get more complex as they gain capability. Factory harnesses tend to get *simpler*: as foundation models improve, less scaffolding is needed for the same result, so elaborate prompt chains and agent handshakes collapse into shorter prompts and native model capability.

Observed signs: skills get shorter and harnesses more general with each model release.

Analogy: SpaceX's Raptor 1 engine was covered in external plumbing and fiddly parts; Raptor 2 fit the same envelope with more performance and far fewer parts.

Implication: a working but fragile brownfield loop built today is worth having; expect it to get smoother with newer models rather than to need a redesign.

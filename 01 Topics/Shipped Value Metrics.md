# Shipped Value Metrics

Measure what reaches users, not how much code agents produce. With agents, lines of code and commit counts rise ~8x while delivery rises ~30%, so volume metrics mislead.

## Track instead

- Feature shipping velocity.
- Merge-acceptance ratio (see [[Mergeability Gap]]).
- Production performance.

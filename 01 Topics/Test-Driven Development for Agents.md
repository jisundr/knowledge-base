# Test-Driven Development for Agents

Making agents follow strict **red-green-refactor**: write a failing test first, then the minimal implementation, then clean up (e.g., via a `/tdd` skill). The failing-then-passing test is an objective, automated signal, so the agent cannot fake or hallucinate success.

A prerequisite for unattended [[AFK Agent Execution]].

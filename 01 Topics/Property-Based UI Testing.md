# Property-Based UI Testing

Instead of scripted test cases, generate randomized streams of UI interactions and assert that stated properties (invariants) always hold, surfacing edge-case bugs before production. **Bombadil** is the tool the speaker names for this.

Fits the runtime tier of the [[Agent Verification Stack]]; the properties to check often come from a spec or [[Statecharts and State Machines]] model.

# Impact-Based Engineering Seniority

When agents compress a two-year migration into five months, "I led a long project" stops signaling seniority. Seniority shifts to:

- **Measurable system impact**: CPU saved, latency improved, incidents prevented, cost cut.
- **Cross-team alignment**: managing dependencies across research, inference, and product.
- **Boundary setting**: designing guardrails, security proxies, and verification loops.

Teams stay "two-pizza" sized (about 5 to 10 engineers) for context and on-call ownership, but skew more senior. Deep domain knowledge (security, networking, operating systems, distributed systems) matters more, not less; engineers whose identity was typing code face the hardest adjustment.

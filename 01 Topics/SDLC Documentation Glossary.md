# SDLC Documentation Glossary

One-line definitions for terms used in the spec and documentation notes. Link to a term with `[[SDLC Documentation Glossary#Term|Term]]`.

### Change brief
A spec for one piece of work: the delta, its scope, and its acceptance criteria.

### Decision documentation theater
Accumulated prose that looks like knowledge but has drifted out of sync with the code.

### constitution.md
A project-wide file of standing principles that every spec and agent run must follow (used by GitHub Spec Kit).

### Nygard format
Michael Nygard's original ADR template: Title, Status, Context, Decision, Consequences.

### MADR
Markdown Architectural Decision Records: a fuller ADR template that adds considered options and their pros and cons.

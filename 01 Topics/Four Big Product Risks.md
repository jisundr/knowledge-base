# Four Big Product Risks

Marty Cagan's checklist for testing an idea before building it:

1. **Value**: will the customer choose to use or buy it?
2. **Usability**: can the user figure out how to use it?
3. **Feasibility**: can engineering build it within our constraints?
4. **Business viability**: does it work for our legal, financial, and operational constraints?

Each risk has an owner in the [[Product Trio]].

# Statecharts and State Machines

Modeling behavior as explicit states and transitions. For agent-written code, a state machine diagram lets an engineer review behavioral logic at a glance instead of reading the implementation. The source mentions a `statechart` agent skill (from the Poteto Stack / PStack toolset) that turns complex state machines into visual diagrams.

Used in the [[Agent Verification Stack]] as a review artifact, and as a natural input to [[Formal Verification (TLA+ and Lean)]] and [[Property-Based UI Testing]].
